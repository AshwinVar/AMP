# AMP Edge Gateway — what a plant PC needs.
#
# Deliberately few packages. This runs on a machine somebody else owns, often
# without internet beyond the broker, and every dependency is a thing that can
# fail an install on a locked-down Windows box six months from now.
asyncua>=1.1,<3          # OPC UA client
pymodbus>=3.6,<4         # Modbus TCP *and* RTU client
pyserial>=3.5,<4         # the serial line itself — see below
paho-mqtt>=2.0,<3        # the one outbound connection
PyYAML>=6.0,<7           # so a config can be YAML instead of JSON
pyfocas>=0.1,<1          # FANUC FOCAS, over a plain socket
imageio-ffmpeg>=0.4,<1   # the camera adapter reads frames through ffmpeg

# WHY pyserial IS LISTED SEPARATELY, when pymodbus is already here. pymodbus
# declares pyserial as an OPTIONAL EXTRA: `pyserial>=3.5; extra == "serial"`.
# Plain `pip install pymodbus` does not bring it, so ModbusSerialClient raises
# on a fresh plant PC and Modbus RTU — the only route into a controller with no
# Ethernet — fails at the customer's site rather than here. Every machine on
# the first moulding floor AMP is going into is exactly that: two DB9 ports and
# no network page in the HMI. serial_listen.py imports pyserial directly as
# well, independent of pymodbus, which is the other reason it is named here
# rather than written as pymodbus[serial].

# WHY pyfocas AND NOT FANUC'S OWN LIBRARY. The normal way to read a FANUC is
# `fwlib`, which is licensed software, ships as a 32-bit DLL, and would put a
# commercial negotiation in front of every FANUC pilot. pyfocas is MIT and
# reimplements the wire protocol on an ordinary socket, so a FANUC gateway
# installs with pip like everything else. It covers four FOCAS functions; the
# adapter documents which, and what that costs.

# WHY imageio-ffmpeg IS DECLARED AND NOT LEFT OPTIONAL. It is only needed by
# the `camera` adapter -- the route for a plant that will allow nothing wired
# into a running cabinet -- and it bundles an ffmpeg binary, so it is the
# largest thing in this file by a wide margin.
#
# It is declared anyway. An undeclared import is a gateway that installs
# cleanly here and raises at the customer's site, on the machine nobody can
# SSH into; that is exactly the failure pyserial produced before it was listed,
# and test_serial_listen.py now refuses any third-party import in the shipped
# gateway code that is not in this file. A one-time download is cheaper than a
# site visit.
